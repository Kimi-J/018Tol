# 绿杖 —— 列夫·托尔斯泰的心灵奥德赛

一个单页长滚动 HTML 作品。以车尔尼雪夫斯基 1856 年提出的「心灵辩证法」为全站的精神操作系统，
以「绿杖传说」为首尾闭环的叙事装置。

**打开方式**：双击 `index.html`。零外部请求、零构建步骤、离线可用。

## 两个已修复的交互缺陷（记录，避免以后重犯）

### 1. 隐藏的 3D 翻页仍然吃点击

`.diary__page` 用 `rotateY(±94deg)` + `opacity:0` 隐藏。**`opacity:0` 不会阻止命中测试**，
而 `rotateY` 之后元素的布局盒（`x=-236 → 471`）依然压在左侧年份列表上。
症状：**只能选一次，之后整个列表点不动**。

修法两层：
- `.diary__page:not(.is-front){pointer-events:none !important}` —— 并且**不做过渡**。
  若让 `pointer-events` 参与 766ms 的过渡，上一页在过渡期间仍是 `auto`，快速连点会丢事件。
- 同一原则推广到所有滚动显现层（`.sky__l` / `.candle__l` / `.syl__l` / `.zwei__l` / `.well__l` / `.dig__line`）。

**反面教训**：不要用 `.cite:has(.conf){pointer-events:auto}` 去「补回」可点性 ——
`.cite` 是嵌套的，`:has()` 会命中**外层的大盒子**（实测 609×212），反而把整片区域变回可点击。

### 2. `<button>` 里的 `<span>` 没有尺寸

`.tb` 是 `<button>`，内部 `<span class="tb__inner">` 是 inline 元素 —— 实测 `inner = 0×0`，
卡片文字被挤成 `44×40` 的小方块，且 `<h4>/<p>` 嵌在 span 里属非法 HTML。
修法：`.tb{display:block;width:100%}`、`.tb__inner{display:block}`，
并将 `<h4>/<p>` 换成 `.tb__title/.tb__body` 两个 block span。

## 十条设计决定

1. **滚动是叙事控制器，不是触发器。** 全站只有一个 `requestAnimationFrame` 循环。
   每个场景把自身在视口中的进度连续插值成一个 CSS 变量（`--p`、`--sp`、`--bp`…），
   CSS 完成剩余的工作。因此所有滚动动画**连续、可逆、无累积**——快速滚动不会错位或堆积。

2. **双线系统是视觉脊柱。** 视口左侧两条轨迹：理性线（冷蓝灰、几何等宽虚线）与信仰线
   （暖土金、手绘实线）。它们随滚动在六种状态之间连续变形：潜伏 → 分离 → 交叠 → 绷紧 → 合一。
   这不是装饰——它是「心灵辩证法」的可见形式。移动端下沉为底部横向带。

3. **天空色温是全站唯一的色彩情绪引擎。** 十个关键帧定义纸色随全书进度漂移，
   从序章的旧纸，经战争与和平的硝烟灰、安娜的舞厅暖灰、深渊的沉落、
   伊凡章的黑、破袋后的灰光、复活的春、出走的雪，回到终章的澄澈。

4. **每一个引文都带可信度标注。** 章内所有 `.conf` 标记都可点击/聚焦展开，
   说明该条史料的确定性、分歧所在，或未被采用的理由。**标注「查无一手出处」的内容，
   本站只记录它是一句流传甚广而无据的话，不引用它。**

5. **宁可留空，不用二手转述填充。** 调研中未能逐字核实的引文，
   在页面上明确写出「尚未逐字核对」，而不是用中文网络流传的版本顶上。

6. **图像采用「尚未显影的底片」占位。** 十个图位是暖纸底 + 极淡斜纹 + 一行说明该处图像功能的
   等宽小字——视觉上属于设计的一部分，不是破绽。替换指令见 `plan/05-图像生成提示词.md`。

7. **首屏只立情绪。** 序章首屏只有标题、一行副标题、一句「向下滚动 —— 开始挖掘」。
   没有按钮，没有说明段落。

8. **滚动本身就是第一个互动。** 序章是一个 340vh 的土层：滚动 = 向下挖掘。
   七个地层各有自己的颜色、颗粒与专属细节（碎石、树根、黏土纹、砂粒），
   挖到底才露出一根极细的绿线——而上面那行字**永远不可读**。

9. **伊凡章的黑袋必须真的压迫读者。** 遮罩把可用视野从 78% 挤到 5%，
   行宽实际变窄，阅读速度真的下降；到 100% 的瞬间，裂纹形状（多边形，不是圆形渐变）
   从内侧撕开，光涌进来。这是全站唯一一次由全暗到全亮的剧烈转场。

10. **终章不做高潮，做澄澈。** 所有噪声、纹理、色彩降为零，只剩最干净的一条墨线。
    全站的双线在此处第一次完全消失——它们最终不必合一，只需退场。

## 已验证的关键更正

调研过程中推翻了若干广为流传的说法，页面按核实结果改写：

| 流传说法 | 核实结果 |
|---|---|
| 他在牌桌上输掉了出生的祖宅 | 1854年秋**卖掉**（5000纸卢布，拆运至35俄里外）；钱先存社会救济署，**约半年后**才用于还赌债。博物馆称此说「只对了一半」 |
| 第二人称叙事实验在《五月的塞瓦斯托波尔》 | 在**《十二月里的塞瓦斯托波尔》**，且用的是「您」(Вы) |
| 临终说「我爱真理，非常爱」 | 长子谢尔盖的原始记录是**断句**：「真理……我爱很多……他们怎么……」 |
| 「没有死亡，有的是光」 | 原文是 **«Вместо смерти был свет»**（取代死亡的，是光） |
| 1901 年被「开除教籍」 | 圣务院用 «отпадение»（自绝），**未用** анафема，结尾还祈求他归回 |
| 他拒绝了诺贝尔奖 | 1902–1906 年**提名 19 次，从未获奖**——不存在「拒绝」 |
| 「心灵辩证法」出自《俄国文学果戈理时期概观》 | 出自《现代人》**1856 年第 8 期**的专论《托尔斯泰伯爵的〈童年〉与〈少年〉。战争小说》 |
| 他编辑了《道德经》的科尼西译本 | 他**亲自翻译**（从儒莲法译与施特劳斯德译转译选编） |
| 《穷人》是托尔斯泰的创作 | 是**据雨果《穷人》改写**（ПСС т.14 注释） |
| 《一个人需要多少土地》结尾是「六英尺」 | 原文是 **три аршина（三俄尺，约2.13米）** |
| 索菲亚抄写《战争与和平》七遍 | **查无出处**，页面不写数字 |
| 《七颗钻石》是托尔斯泰作品 | 俄文原作**无法确定**，页面直接标注「归属存疑」 |
