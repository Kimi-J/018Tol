## 4. 生成后的统一后处理（**必须做，四步**）

用任何图像工具（PIL / ImageMagick / 你的工具链）对**每一张**执行：

1. **降饱和**：整体饱和度 −18% ~ −25%（天空与草地尤其要压）。
2. **提黑位**：把最深的黑抬到 `#1A1512` 附近 —— 画面里不留纯黑 `#000000`。
3. **压高光**：把最亮点压到 `#F2ECE0` 附近 —— 画面里不留纯白 `#FFFFFF`。
4. **叠纸噪**：叠一层极细灰度噪声，不透明度 3–5%，混合模式 `柔光`。

做完后**每张图的中间调都应接近 `#B9AC96`**，与网页纸色 `#F4EFE4` / `#EBE3D4` 同一色系。

**导出**：JPEG，quality 88–92，sRGB，单张控制在 400 KB – 1.5 MB。

## 5. 替换 HTML：**保留外壳，只换内部**

`index.html` 里每个占位块长这样：

```html
<div class="slot" data-slot="SLOT-03" style="aspect-ratio:4/3">
  <span class="slot__label"><b>SLOT-03 · 4:3</b>《战争与和平》手稿的一页<br>替换：assets/img/03-war-and-peace-ms.jpg</span>
</div>
```

**把里面的 `<span class="slot__label">…</span>` 整段换成 `<img>`，外壳 `<div class="slot" …>` 原样保留。**

替换后：

```html
<div class="slot" data-slot="SLOT-03" style="aspect-ratio:4/3">
  <img src="assets/img/03-war-and-peace-ms.jpg"
       alt="《战争与和平》手稿的一页"
       loading="lazy" decoding="async"
       width="2400" height="1800">
</div>
```

### ⚠️ 三条不可违反的规则

1. **`<div class="slot" …>` 外壳绝对不能删。**
   宽高比（`style="aspect-ratio:…"`）与宽度都挂在它身上。删掉外壳，图片会按原始像素铺开——
   实测会撑到 1036–2400px 宽，整页版面被撑破。
   你只需要把**里面的占位文字**换掉。

2. **`width` / `height` 属性填你实际生成的像素值**，不要照抄上面的示例数字。

3. **只改这 10 个 `<div class="slot">` 内部的文字。** 它们外面包的 `<div class="inner">`、
   `<section>`、说明段落**一个都别动**；不要新增或修改任何 CSS —— `.slot img` 的样式
   （`position:absolute; inset:0; object-fit:cover`）已经定义好了。

### 一句话记法

> `data-slot` 的外壳留着，`slot__label` 的内容换掉。

### 出错时怎么认出来

| 症状 | 原因 |
|---|---|
| 某张图特别宽、把版面撑出横向滚动条 | 把 `.slot` 外壳一起删了 |
| 某张图特别扁（只有几十像素高） | 把外壳的 `style="aspect-ratio:…"` 删了 |

改完任何一个槽位，都可以跑第 7 节的验收器确认。

## 8. 遇到问题怎么办

| 情况 | 处理 |
|---|---|
| 生成结果出现了文字/字母 | **作废，重新生成**，并在提示词里再强调一次 `no text, no letters, no numerals` |
| 风格偏了（太艳 / 太亮 / 太蓝） | 先做第 4 节后处理；仍偏就重生成，不要靠调色硬救 |
| 生成工具不支持指定宽高比 | 先生成，再**按第 3 节的宽高比中心裁切**，裁切后勿拉伸变形 |
| 个别槽位实在生成不出来 | **宁可留空**，不要用风格不符的图顶上。该槽位保持原样（连 `slot__label` 一起留着），并在交付说明里列出哪几个没做 |
| 文件太大 | 降 quality 到 85，或长边缩到 2048；单张不要超过 2 MB |
| 版面被撑破 / 图片特别扁 | 见第 5 节末尾的「出错时怎么认出来」 |
