| 项 | 内容 |
|---|---|
| **钩子** | 五十岁那年，他把绳子从房间里拿了出去。 |
| **知识点** | ① 绳子段在《忏悔录》**第四章**，原文是 **«вынес из своей комнаты шнурок»**（拿出去），**不是**流行的「прятал」（藏起来）② 井中旅人寓言（第四章，俄文逐字）：旅人／**无水的井**／**张着大嘴的龙**／**井壁裂缝里的一丛野灌木**（不是「树枝」泛称，也不是藤）／**一黑一白两只老鼠**绕着枝条均匀走动并啃噬／蜜在**叶子上**、以舌够取 ③ 托尔斯泰的关键补充：这蜜**已经不再使他快乐**——常被误读为「及时行乐」，其实恰相反 ④ 结句：「这不是寓言，这是真实的、无可争辩的、人人都明白的真理。」⑤ 他亲手指认自己那两滴蜜的名字：**对家庭的爱，以及我称之为艺术的写作** |
| **互动** | **I-22 井中旅人**（签名）：440vh 纵向场景，七层逐层揭示（野兽→井壁→野灌木→黑白二鼠→龙→蜜滴→伸出的手）。**末层把前六层同时压暗，只留蜜滴一点微光** —— 这个收束对应寓言的结句。约束：无 jump scare、无音效、无摇摆晃动；压迫感必须来自结构本身 |
| **情绪值** | 2 → **0（全站最低点）** |
| **视觉锚点** | 七层 SVG 线描 |
| **呼吸时刻 ③** | 「如果我是这样一个人：住在森林里，并且知道没有出口 —— 我本可以活下去；但我是一个在森林里迷了路的人。」（第四章，俄文逐字）。**全站唯一一次光自上而下** |

## 防文字墙的落实方式

| 手段 | 具体做法 |
|---|---|
| 长分析拆成步进卡片 | 三段论三行逐行出现；列文割草、法庭机器按滚动分阶段 |
| 每屏必须有视觉锚点 | 24 个滚动驱动场景 + 9 个 Canvas + 10 个图像位；实测各章平均 800–1200 中文字/屏 |
| 引文独立版式 | 大字、宽留白；俄文原文一律降 0.92 倍字号、更淡、斜体，始终从属 |
| 日期/编号/注释用等宽 | 全部 `--font-mono` |
| 禁止空洞形容词 | 所有评价性表述均落到具体文本或史实；未核实者直接标注 |
