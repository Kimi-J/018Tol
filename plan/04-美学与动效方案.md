# 《绿杖》美学与动效方案 v1

> 本文件是全站视觉与动效的唯一规范来源。所有 CSS 变量、动效时长、转场逻辑必须从这里取值，不得即兴发明。

---

## 一、气质定位（一句话）

**一本正在被翻开的手稿，一间光线缓慢移动的博物馆展厅，一片不断变换的俄罗斯天空。**

三个参照物（用于校准每个决策）：
1. **手稿**——墨迹、删改线、页边批注、纸张纤维；
2. **博物馆展厅**——克制的打光、极宽的留白、异物并置（手稿 / 肖像 / 地图 / 实物）；
3. **俄罗斯乡野天空**——全站唯一的"色彩情绪引擎"，从灰白到铅青到极暗到晨光。

关键词：庄严、克制、深沉、诗性、内省、留白、呼吸感。

**禁止**：霓虹、赛博、大面积紫色渐变、廉价金色、过度发黄滤镜、发光圆球、科技网格、漂浮粒子、廉价装饰性 SVG。

## 三、质感系统（三层叠加，全部低对比）

1. **纸纤维**：SVG `feTurbulence` (baseFrequency 0.8, numOctaves 3) 生成的噪声，`opacity: 0.035`，`mix-blend-mode: multiply`。fixed 定位，不随滚动。
2. **旧书页噪点**：极细点阵（SVG pattern，1px 点，8px 间距），`opacity: 0.02`。
3. **墨迹边缘**：仅用于引文块与手稿卡片——用 CSS `filter: url(#roughen)`（`feTurbulence` + `feDisplacementMap`，scale 1.5–2.5）让矩形边缘产生极轻微的不规则。**必须可关闭**：`prefers-reduced-motion` 或低性能设备下降级为普通边框。

**硬性约束**：三层叠加后，正文对比度必须 ≥ 7:1（WCAG AAA）。若噪点让某处文字发灰，降低噪点而不是降低文字对比。

## 四、字体系统

### 4.1 字族栈（不依赖外部字体，保证离线可用）

```css
--font-display: "Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", "Times New Roman", serif;
--font-body:    "Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", Georgia, serif;
--font-mono:    "Cascadia Mono", "Consolas", "SFMono-Regular", "DejaVu Sans Mono", monospace;
--font-hand:    "Segoe Script", "Bradley Hand", cursive; /* 仅用于手迹卡，且仅拉丁字符 */
```

中文正文用**宋体族**（衬线，有文学气质且屏幕可读），标题用同一族但更重字重 + 更紧字距（**只允许正向 tracking，禁止负字间距**）。

### 4.2 字号阶梯（基于 `clamp()` 流体排版）

| 层级 | 规格 | 用途 |
|---|---|---|
| 巨型引文 | `clamp(2.2rem, 5.2vw, 4.6rem)` / lh 1.25 / ls 0.01em | 全屏大引文（如"申冤在我，我必报应"） |
| 大引文 | `clamp(1.6rem, 3.2vw, 2.6rem)` / lh 1.4 | 章节内引文块 |
| 章标题 | `clamp(2.6rem, 6vw, 5rem)` / lh 1.05 | 乐章标题 |
| 节标题 | `clamp(1.4rem, 2.4vw, 1.9rem)` / lh 1.3 | 小节 |
| 正文 | `clamp(1.02rem, 1.15vw, 1.14rem)` / lh 1.9 | 行长 ≤ 34 中文字（`max-width: 37ch` 中文按 1ch≈0.5em 折算，实测取 `max-width: 32em`） |
| 引文出处 | `0.78rem` / ls 0.06em / mono / `--ink-3` | 档案体 |
| 数字编号 | `0.72rem` / ls 0.14em / mono / uppercase | 档案体 |

**混排规则**：中文与拉丁数字之间插入 `0.08em` 间隙（用 `text-spacing` 或手写 span）；俄文原文引用时字号降 0.92 倍，颜色 `--ink-2`。

## 五、构图逻辑

**文学节奏，不是营销模块。** 每屏使用以下构图型之一，连续两屏不得用同一型：

| 型 | 描述 | 例 |
|---|---|---|
| A 单点 | 全屏只有一个视觉锚点 + 一行大字 | 奥斯特里茨天空 |
| B 疏密并置 | 一侧极密（手稿、档案），一侧极空 | 日记翻页器 |
| C 横向带状 | 内容横向流动，纵向只推进一次 | 与太阳赛跑、遗产地图 |
| D 纵深 | 元素用 scale/translateZ 制造隧道感 | 黑袋穿越、井中旅人 |
| E 对位 | 左右/上下两个不对称但平衡的块 | 双线、两个面孔 |
| F 档案墙 | 网格化的小卡片群，密度高但每块字少 | 回声墙、年表 |

**首屏规范**：只有 ① 全屏天空/土地 ② 一行主标题 ③ 一行副标题（≤18 字）④ 底部一个"向下挖掘"的微暗示（一条向下渐隐的墨线 + 一个 `scroll` 提示的极淡等宽小字）。**不放任何按钮，不放任何说明段落。**

## 六、动画三层节奏

| 层 | 时长 | 缓动 | 职责 | 例子 |
|---|---|---|---|---|
| **背景层（慢）** | 8–40s 循环 / 或纯滚动驱动 | `linear` | 光线的色温与方向、天空渐变、纸面明暗 | 全站天空色温随滚动进度从 `#F4EFE4` 漂移到 `#A79880` 再到 `#EBE3D4` |
| **转场层（中）** | 900–1600ms | `cubic-bezier(.22,.61,.36,1)` | 章节之间的"状态转化" | 压缩→舒展、黑暗→明亮、混乱→清晰、狭窄→辽阔 |
| **交互层（快）** | 120–260ms | `cubic-bezier(.2,.8,.2,1)` | 按钮、悬停、点击反馈 | 墨线从点击点扩散 8px、亮度 +6% |

### 6.1 滚动驱动原则（硬规范）

- 滚动是**叙事控制器**：一个滚动进度值 `p ∈ [0,1]` 驱动一个场景的**连续插值**，而不是"进入视口触发一次动画"。
- 所有滚动动画必须：
  1. **连续**——中间任意 `p` 都有确定状态，没有跳变；
  2. **可逆**——向上滚动逐帧精确复原；
  3. **稳定**——快速滚动（一次滚轮 3000px/s）不得错位、闪烁、堆积；
  4. **无累积**——禁止在 `scroll` 回调里做 `+=` 累加。
- 实现：单个 `IntersectionObserver` 只用来**登记/注销**活跃场景；实际进度用 `getBoundingClientRect()` 在统一的 `rAF` 循环里计算一次，写入 CSS 自定义属性 `--p`，由 CSS 完成插值。
- `prefers-reduced-motion: reduce`：所有滚动驱动动画降级为"分段静态呈现"（每 0.25 进度一档，`transition` 400ms），不得完全不显示内容。

### 6.2 章节转场 = 状态转化（禁止普通淡入淡出）

| 转场 | 状态转化 | 实现要点 |
|---|---|---|
| 序章 → 第一乐章 | **狭窄 → 辽阔** | 土坑的取景框从 100% 缩到 34% 并上移，露出纸面全景 |
| 第一乐章 → 战争与和平 | **密集 → 疏朗** | 档案卡群向两侧滑出并压缩为两条细线，中央让位给天空 |
| 战争与和平 → 安娜 | **开阔 → 逼仄** | 天空比例从 100% 压到 22%，底部升起车厢/舞厅的暗色带 |
| 安娜 → 深渊 | **明亮 → 全暗** | 蜡烛熄灭后不做淡出，而是**从烛芯一点向外扩散的暗**（`radial-gradient` 半径从 0 到 160%） |
| 深渊 → 伊凡 | **全暗 → 全暗（更深）** | 不转场，直接沉下去；靠"倒计时数字"建立新章节 |
| 伊凡 → 复活 | **暗 → 光（破袋）** | 黑袋被撑破的瞬间，光以**撕裂边缘**的形状扩散，不是圆形渐亮 |
| 复活 → 出走 | **清晰 → 混乱** | 法庭网格线开始抖动、错位，然后被雪夜的横向笔触覆盖 |
| 出走 → 终章 | **混乱 → 澄澈** | 所有噪声、纹理、色彩降为 0，回到最干净的 `--paper-0`，只剩一条墨线 |

### 6.3 呼吸时刻（章与章之间）

规格：**满屏引文 + 缓慢光影**，无交互控件，纵向 140–200vh（滚动时引文缓慢上移并微调字距，光从左上到右下走完一次 12–20s 的循环）。全站共 5 处，分别安放在：
1. 序章之后（绿杖/幸福之问）
2. 战争与和平之后（天空/死亡）
3. 安娜之后 / 深渊之前（爱与被惩罚）
4. 深渊之后（生命的意义）
5. 出走之前（离开）

## 七、双线系统（全站视觉脊柱）设计规范

### 7.1 物理形态

- 两条 SVG path 固定在视口左侧（桌面 `left: 3.2vw`，宽度 `64px`；移动端下沉为底部 `height: 44px` 的横向带）。
- **理性线**：`--line-reason`，`stroke-dasharray: 8 5`（等宽虚线），`stroke-width: 1.25`，`stroke-linecap: square`。
- **信仰线**：`--line-faith`，实线，`stroke-width: 1.6`，`stroke-linecap: round`，路径点经过轻微的手绘扰动（`feTurbulence` 位移 0.8px）。

### 7.2 五种状态（随章节变形）

| 状态 | 名称 | 几何 | 对应章节 |
|---|---|---|---|
| S0 | 潜伏 | 两条线重叠为一条，颜色混合为中灰 | 序章（还没分化） |
| S1 | 分离 | 两线相距最远（±18px），各自抖动频率不同 | 第一乐章（青年：规则 vs 欲望） |
| S2 | 交叠 | 两线正弦交叉，交叉点密度高 | 第二、三乐章（战争/和平、安娜/列文） |
| S3 | 绷紧 | 两线被拉成几乎平行且极近，张力最大，出现细小裂纹 | 深渊、伊凡（危机） |
| S4 | 合一 | 合并为一条更粗的线，但保留两种颜色的**分段交替**（不是叠成一色） | 复活、出走、终章 |

### 7.3 变形实现

线路径由 `d` 属性的 `M/C` 段插值生成：预先为每个状态计算一组控制点，用 `p` 在相邻状态间线性插值后写入 `d`。**不用** `transition: d`（浏览器支持与性能不可靠），改在 `rAF` 中直接写属性（每条线 ≤ 14 个控制点，性能安全）。

### 7.4 语义层

双线不只是装饰：每个场景可以"把某一段文本挂在某一条线上"——引文旁出现该线的极小色点，读者由此建立"这是理性的声音/这是信仰的声音"的直觉映射。**禁止**用颜色区分好坏。

## 八、交互反馈规范

- **禁止所有元素都是圆角胶囊。** 主按钮形态：**墨线框**——1px `--ink-2` 边框，方角（`border-radius: 1px`），悬停时边框从点击点向外扩散成双层（`::before` scale 0→1，180ms），文字亮度 +6%。
- **次要交互**（星丛卡、翻牌）：无边框，只有一条 1px 下划线；悬停时下划线从左侧延伸至 100%（220ms），并从 `--ink-3` 变 `--ink-1`。
- **可拖拽元件**（钟摆、滑杆、摆荡条）：游标 `grab`/`grabbing`，拖拽时目标元素 `filter: brightness(1.06)`，松手后有 ≤400ms 的过冲回弹。
- **禁止**：缩放弹跳（`scale(1.05)` 之类）、阴影发光、彩色光晕。
- **键盘可达**：所有交互元素可 Tab 聚焦，`focus-visible` 为 2px `--blue` 外框 + 2px 偏移。

## 九、图像策略

优先级：**CSS/SVG/Canvas 再创作 > 公有领域历史素材 > 生成图**。

1. **再创作**（首选）：手稿纹理、地图、树林、天空、庄园剪影、四季——用 SVG 路径 + Canvas 噪声绘制。风格统一为**低饱和、自然光、高噪点**。
2. **历史素材**（若接入）：仅限公有领域——普罗库金-戈尔斯基 1908 彩色照片（美国国会图书馆）、列宾画作（公有领域）、1910 年前照片。必须统一处理：`filter: grayscale(0.15) contrast(0.96) sepia(0.06)` + 纸纹叠加 + 4px 不规则边框。
3. **生成图占位**：所有需要生成图的槽位在 HTML 中留 `data-slot` 占位块（带准确的宽高比与可见的极淡占位线），并在 `plan/05-图像生成提示词.md` 中给出傻瓜式替换指令。

**每个图像的硬规范**：必须服务一个具体的叙事功能（引文背景 / 时代定调 / 空间建立），**不得**作为"填充美感"的装饰。空槽位在未替换时也必须能看——占位块本身设计为"尚未显影的底片"（`--paper-2` 底 + 极淡对角线 + 一行 mono 小字说明此处的图像功能）。

## 十、性能与可访问性底线

- 全站零外部请求，零构建步骤，单文件 `index.html`（可选外链 CSS/JS 分文件，但默认内联以保证双击可用）。
- 同时运行的 `rAF` 循环 **最多 1 个**，统一调度所有场景。
- Canvas 元素仅 2 个以内，`devicePixelRatio` 上限 2，`will-change` 只加在正在变化的元素上，用完即删。
- 低端设备降级：`navigator.hardwareConcurrency < 4` 或屏幕 < 768px 时，噪声层关闭、双线控制点减半、Canvas 帧率降至 30。
- 正文对比度 ≥ 7:1；所有纯装饰元素 `aria-hidden="true"`；每个场景有 `role="region"` + `aria-label`。
- 打印样式：双线隐藏，噪点关闭，引文保持黑字白底。

## 十一、音乐/声音

**默认无声音**。若加入，只能是：① 1908 年托尔斯泰留声机录音的 3 秒片段（作为"他自己的声音"章节的点击触发，默认静音）；② 无。**禁止**背景音乐、禁止环境音效自动播放。
