# 《绿杖》互动清单 v1

> 原则：**互动即诠释**。禁止为动而动——每个交互必须锚定一个具体的文本细节、场景或思想点。
> 每个条目给出：机制（怎么操作）/ 诠释目的（它在解读什么）/ 文字锚点（绑定的原文或史实）/ 技术形态 / 实现难度。

---

## 第一部分 · 全站层

### I-00 双线系统（贯穿全站，视觉脊柱）
- **机制**：固定在视口左侧的两条 SVG 轨迹（理性=冷蓝灰等宽虚线；信仰=暖土金手绘实线）。滚动到不同乐章时，两线的距离、交叉密度、张力状态连续变形（S0 潜伏 → S1 分离 → S2 交叠 → S3 绷紧 → S4 合一）。可点击任意位置在当前乐章的两线之间"挂号"一条极细的横向刻线，把当前引文标记为"理性之声"或"信仰之声"。
- **诠释目的**：把车尔尼雪夫斯基 1856 年提出的「心灵辩证法」——他关心的不是心理活动的**结果**，而是心理**过程本身**、它的形式、规律、矛盾与流动——变成一个**可以看见其过程**的动态系统。两线不是"好与坏"，而是同时存在于一个人身上的两股力。
- **文字锚点**：车尔尼雪夫斯基《俄国文学果戈理时期概观》(1856) 关于「диалектика души」的定义段落。
- **技术**：SVG path，控制点数组插值，`rAF` 统一调度。**难度：中高**

### I-01 档案体元信息层（全站微交互）
- **机制**：全站每一个引文块右下角有一个等宽小字出处（如 `ИСПОВЕДЬ · 1879–1882 · ГЛ. IV`）。悬停时出处行展开 0.5 秒，显示"可信度标注"（已核实 / 说法不一）。点击"说法不一"的标注浮出一个短卡片，列出各版本说法。
- **诠释目的**：**把史学诚实变成设计语言**。让读者随时看到"这条史料的确定性有多大"——这本身就是对"让托尔斯泰自己说话"这一纲领的界面化。
- **技术**：纯 CSS + 少量 JS。**难度：低**

### I-02 呼吸时刻（5 处，章间冥想页）
- **机制**：满屏一句引文 + 缓慢光影（12–20s 循环的光线走向），无控件；滚动时引文缓慢上移、字距极微变化。
- **诠释目的**：给情绪曲线留出**下落与回升的空间**；也是"留白与呼吸感"的实体化。
- **技术**：CSS 动画 + 滚动插值。**难度：低**

## 第二部分 · 序章「绿杖」

### I-03 绿杖挖掘（签名互动 ①，首尾闭环）
- **机制**：序章是一块纵向 300vh 的土层。滚动 = 向下挖掘：土层分 7 个地层（腐殖土 / 黄土 / 黏土 / 碎石 / 树根层 / 砂层 / 深色土），每层有各自的颜色与颗粒度。挖到最深处露出一根极细的绿色横线（绿杖本身），上面浮出一行几乎看不清的字（让所有人幸福的秘密——但**永不显示完整内容**）。终章反向复用：同一块土层、同一根绿杖，但视角从"向下挖"变成"向上看"，绿杖横在画面中央，上面那句话仍未显示。
- **诠释目的**：把"5 岁听哥哥说沟里埋着绿杖"这一传说变成**读者的身体动作**。全站皆是一场寻找绿杖的奥德赛；而秘密的不可读，正是托尔斯泰一生的处境。
- **文字锚点**：托尔斯泰《回忆录》(1903–1906) 关于绿杖的原话 + 他要求葬在绿杖埋藏处的遗愿。
- **技术**：Canvas 土层（噪声 + 层色）+ 滚动驱动的挖掘进度；或纯 CSS（多层 div + mask）。**难度：中高**

### I-04 序章呼吸时刻：幸福之问
- **机制**：全屏暗底，两线从画面中央一点分开（S0→S1 的第一次变形）。一句引文缓缓显形。
- **诠释目的**：让"双线"在读者还没被告知概念之前先被看见。

## 第三部分 · 第一乐章「我是谁」

### I-05 日记翻页器（签名互动 ②）
- **机制**：一本横向的"日记"。左侧是年份拨盘（1847 / 1851 / 1855 / 1858 / 1862 / 1879 / 1884 / 1895 / 1908 / 1910），点击年份，右侧纸页**从右向左翻过来**（3D `rotateY` + 背面隐约透出上一页的字迹反像）。每一年只呈现 1–3 则真实日记摘句（短句大字），配一行等宽小字日期。
- **诠释目的**：托尔斯泰从 1847 年记日记记到临终前——这不是文学成就，这是一种**持续 63 年的自我审讯装置**。翻页的动作让"一生"变成可触摸的厚度。
- **文字锚点**：真实日记条目（须由调研组提供准确原文与出处）。
- **技术**：CSS 3D transform + JS 状态机。**难度：中**

### I-06 规则清单勾选（签名互动 ③，与 I-05 同场景）
- **机制**：青年托尔斯泰的"规则清单"（правrules/правила）以手写体列表呈现，每一条左侧有一个极小的方形墨框。读者可以点击勾选。**勾选后不显示"完成"，而是显示该条规则后来被他自己划掉的年份**（如"1854：划掉"）——因为他在日记里一次次列出规则又一次次失败。
- **诠释目的**：这是全站最尖锐的自我反讽。读者执行"自律"的动作，得到的回应是"他也失败了"。这就是心灵辩证法的第一次示范。
- **文字锚点**：1847 年前后的规则清单真实条目 + 日记中"我又违反了规则"类记录。
- **技术**：纯 DOM + CSS。**难度：低**

### I-07 输掉的祖宅：平面图剥离
- **机制**：亚斯纳亚波利亚纳庄园的极简平面图（SVG 线稿：主楼 + 两座厢房 + 林荫道）。滚动到"1854 年他在牌桌上输掉了自己出生的房子"时，主楼的多边形**逐块被拆解**（每块沿对角线飞出画面），剩下两座厢房。地面留下一块虚线轮廓。读者可以把鼠标移到空轮廓上，读到一行小字："此后 56 年，他住在厢房里。"
- **诠释目的**：把一个抽象损失变成一次**建筑级别的消失**。这是全站第一个"钩子"的视觉兑现。
- **文字锚点**：输掉主楼的史实（年份与经过须核实）+ 此后住厢房的记载。
- **技术**：SVG 多边形 + 滚动插值。**难度：中**

### I-08 心灵辩证法点题：过程而非结果
- **机制**：一句话在屏幕中央；屏幕被一条竖线分成左右两半。左半写"结果"（显示为一行概括性的结论文字，然后**被划掉**）；右半写"过程"（显示为十几个短句的流动，像心电一样依次亮起、然后淡去、又被新的盖住，永不停留）。读者移动鼠标横向滑动，可以看到左边文字越来越淡、右边越来越清晰。
- **诠释目的**：这正是车尔尼雪夫斯基的定义的可感知化：他关心的不是心理活动的结果，而是过程本身。**这是全站的"操作系统"在此被显式安装。**
- **文字锚点**：车尔尼雪夫斯基 1856 年评论原句。
- **技术**：Canvas 或 DOM + 定时器。**难度：中**

## 第四部分 · 第二乐章 深潜①《战争与和平》

### I-09 奥斯特里茨天空（签名互动 ④）
- **机制**：整屏 100% 是天空——从战场的硝烟灰向高处过渡到极淡的青白，云层以极慢速度横移（40s 循环）。画面中央**什么都没有**。滚动时，引文从底部一行一行地极缓浮现，直到最后一行停在画面上三分之二处的黄金分割点。天空的对比度随滚动降低，最后几乎只剩一片白。
- **诠释目的**：安德烈公爵躺在地上，看到的不是战争，而是"那么高、那么静、那么庄严的天空"。**天空的内容就是"没有内容"**——这一屏的空白就是诠释本身。这个交互之所以成立，正因为它几乎不"交互"。
- **文字锚点**：安德烈仰望天空的原文。
- **技术**：Canvas 渐变 + SVG 云层。**难度：中**

### I-10 彼埃尔钟摆（签名互动 ⑤）
- **机制**：一个可拖拽的钟摆。摆锤停在极点时，展开该极端对应的**原文引句**（例如一极是"我要活得有意义"式的自我期许，另一极是他被欲望/虚荣支配时的自述）。拖拽过程中，摆锤下方有一行极小的等宽字实时显示"当前倾角"。松开后摆锤会摆动 3–4 次然后停在阻尼位置——**停留的位置由你松手时的速度决定**，不预设答案。
- **诠释目的**：彼埃尔是《战争与和平》里最典型的"摆荡者"：从放荡到共济会到战场到被俘到卡拉塔耶夫。钟摆不是比喻，而是他的**运动形式**。
- **文字锚点**：彼埃尔不同心境的两段原文引句（须准确）。
- **技术**：SVG + 指针拖拽 + 阻尼物理。**难度：中**

### I-11 历史微积分（签名互动 ⑥）
- **机制**：画布上先有无数的极小箭头，每个箭头的方向是**随机的**、速度**各不相同**、彼此**看不出关系**。随着滚动推进，箭头逐渐开始"对齐"——不是被某个中央力量吸引，而是**每一支箭头都根据其邻近箭头的平均方向微调自己**（boids 式局部规则）。约 40% 进度时，它们汇成一道洪流。进度到 100% 时，洪流又散开，留下几支各行其是的箭头。
- **诠释目的**：这是托尔斯泰历史观的可视化：历史的运动不是伟人意志的结果，而是无数个体微小、盲目、各自为政的行动的**总和**——他在《战争与和平》中称之为"微分"与"积分"。**关键在于"没有中心"**：任何在画面中央放一个发光核心的做法都是对这一思想的背叛。
- **文字锚点**：《战争与和平》第三卷关于历史运动与微积分的论述段落。
- **技术**：Canvas，`n ≤ 420` 个粒子，30fps 上限。**难度：中高**

### I-12 娜塔莎的月夜：窗台
- **机制**：一个非对称构图：画面右上是一个窗框（暗），左下是室内（更暗）。滚动时，月光从窗框投射到地板上，形成一个缓慢移动的光斑。引文沿着光斑的边缘排布（斜向）。悬停光斑，月光的色温轻微变暖（回忆的温度）。
- **诠释目的**：奥特拉德诺耶之夜是《战争与和平》里最著名的"呼吸时刻"。这里不做戏剧化处理，只做**光和一句台词**。
- **技术**：CSS 渐变 + 混合模式。**难度：低**

### I-13 双线结构图：家庭与历史
- **机制**：一张极简的结构图——两条主线（安德烈/娜塔莎、彼埃尔/海伦）加一条历史线（1805–1812–1820）。读者可以拖拽时间轴，看三条线在各卷的交汇点浮出小标签（点击展开一句话）。图上不出现"剧情概括"式长文本。
- **诠释目的**：把"多视角 + 家庭叙事 + 历史决定论"这三件事的关系变成一张**可操作的图**，而不是一段说明文。

### I-14 波罗金诺：你在这里
- **机制**：一张极简的波罗金诺战场地图（等高线 + 几个村庄名 + 几点火光）。滚动时，地图上一个极小的圆点（"彼埃尔的位置"）缓慢移动，同时在地图边缘的等宽小字里实时打印该处的独立事件片段（"第 X 炮台，某团，某个人在做某事"）。不做全局概览。
- **诠释目的**：托尔斯泰在波罗金诺的写法是**把战役缩小到一个困惑的平民视角**。这个交互把"宏大历史 = 你当时站在哪里"这句话变成操作。

## 第五部分 · 第三乐章 深潜②《安娜·卡列尼娜》

### I-15 舞会追踪镜头（签名互动 ⑦）
- **机制**：一个横向的"镜头"。画面是一个竖高、暗底、只有几处金色光斑的舞厅（极简：几条竖线代表人影，几点暖光是烛台）。读者横向滚动或拖动，镜头会**跟随着一个移动的光点**——镜头有惯性（延迟跟随 + 轻微过冲），像斯坦尼康。当镜头最终追上光点并停住，画面中央才浮出引文。
- **诠释目的**：托尔斯泰写安娜出场用的是**弗龙斯基的眼睛**——他没有描写安娜，他描写的是"所有人都开始看她"。镜头的**延迟**就是这个效果：你永远比安娜慢半步。
- **文字锚点**：舞会上弗龙斯基看见安娜的段落。
- **技术**：横向滚动容器 + 惯性跟随（lerp）。**难度：中**

### I-16 粉笔字求婚（签名互动 ⑧）
- **机制**：一张绿色的呢绒牌桌（列文与吉提用粉笔在桌上写首字母）。屏幕上只有几个被抹掉的粉笔痕迹。读者用鼠标在桌面上"擦拭"（拖动清除一层极薄的粉笔灰），每擦开一处，一个首字母显现；擦满全部字母后，整句在桌上浮现成一行完整的粉笔字，粉笔灰的颗粒同时轻轻落下。
- **诠释目的**：这是文学史上最著名的"不敢说出口"的场面。整段对话由首字母承担——**因为那些话不能说出口**。让读者必须亲手擦出来，才和列文一样经历"只有他们两个人懂"。
- **文字锚点**：粉笔首字母求婚段落原文。
- **技术**：Canvas 擦除（`globalCompositeOperation: destination-out`）。**难度：中**

### I-17 安娜的蜡烛（签名互动 ⑨，全站情绪最暗的交互之一）
- **机制**：画面正中一支蜡烛，火苗用 Canvas 绘制（两层同心的暖色光晕 + 极小的随机抖动，抖动幅度由"当前阅读进度"驱动）。随着读者滚动阅读她最后的章节，火苗逐渐变小、抖动变剧烈、"风"变大；最后一段读完后，火苗**不是熄灭成黑**，而是"变得更亮了一下，照亮了一切"——然后才彻底灭掉。灭掉之后，屏幕上浮现"生命之书"的原文，文字由暗转极暗，只保留一行烛泪般的暖色残影。
- **诠释目的**：安娜的死亡段落里，托尔斯泰写的蜡烛是"照亮了她以前处在黑暗中的一切……噼啪作响，开始昏暗，永远熄灭了"。**先亮后灭**这个顺序是原文的，不能被简化成"渐暗"。
- **文字锚点**：安娜卧轨前的蜡烛段落原文。
- **技术**：Canvas 火焰 + 滚动插值。**难度：中**

### I-18 弗龙斯基的马：叠化对照
- **机制**：两个画面上下叠放，由一个滑杆控制叠化比例。上：赛马中弗鲁-弗鲁的最后一次跳跃（极简剪影：马、骑手、障碍）。下：安娜在火车站的身体（同一构图的剪影，只是把马换成了铁轨）。滑杆拖动时，两个剪影的**共同线条**（脊椎那条弧线）被高亮成同一条 `--rust` 色曲线，并在两侧显示同一句描述的两种版本。
- **诠释目的**：托尔斯泰把弗龙斯基的落马与安娜的命运写成同一个动作——**折断的脊背**。这个叠化不是外部评论，是把原文里已经存在的对位关系显影出来。
- **技术**：SVG 剪影 + 滑杆插值 + 路径高亮。**难度：中**

### I-19 列文割草：身体的节奏
- **机制**：极简：一个横向的、由无数细小墨点组成的"草浪"。滚动时，一排点被依次"割倒"（旋转 90° 并下沉），同时屏幕边缘出现一行极短的引文片段，只有一个词会亮起。割完一条，下一条开始。
- **诠释目的**：割草在《安娜》里是列文唯一真正获得平静的时刻——**因为他终于不思考了**。这个交互刻意的机械重复性就是诠释：思想停下来了。
- **技术**：DOM 或 Canvas 粒子。**难度：低**

### I-20 题词：申冤在我，我必报应
- **机制**：全屏极暗，画面中央只有一行巨大的题词。读者滚动时，这行字的**每一个字逐个变得沉重**（字重增加、颜色加深、轻微下坠 2px），直到整句像刻在石上。然后屏幕向右滑开，露出下一场景。
- **诠释目的**：这句出自《罗马书》12:19 的题词是全书的道德困境。托尔斯泰用它起誓要惩罚安娜，却爱上了她。**"变沉重"这个动作就是那句题词对作者本人施加的压力。**

### I-21 安娜 vs 列文：双线分屏
- **机制**：屏幕被一条曲线（就是全站的"信仰线"）分成两半。左半是安娜的时间（越来越快、越来越暗的短句流）；右半是列文的时间（越来越慢、越来越亮的短句流）。读者横向拖动曲线，可以改变两半的比例，但**这条曲线本身也在缓慢地向上/向下漂移**——你无法让两边同时稳定。
- **诠释目的**：这是全站双线系统在作品层面的具体兑现：《安娜》的平行结构不是两条故事线，而是**两种时间的速度差**。

## 第六部分 · 间章「深渊」

### I-22 井中旅人（签名互动 ⑩）
- **机制**：一个纵向的、几乎全暗的场景，从下往上分层揭示（滚动向下 = 视线向下沉）。共 7 层，每层揭示时只有该层被极弱的冷光照亮：
  1. 井口上方：追赶他的野兽（暗影轮廓）
  2. 井壁：他抓住的那根树枝
  3. 井底：张开嘴的龙
  4. 树枝根部：一黑一白两只老鼠，正在啃咬
  5. 树枝尖端：一滴蜜
  6. 他的手：正伸向那滴蜜
  7. 全景收束：以上同时存在于一个画面里，光熄灭，只剩蜜滴的一点微光
- **诠释目的**：这就是《忏悔录》第四章的东方寓言，也是全站情绪的最低点。**关键约束：绝不做成"恐怖游戏"**——没有 jump scare，没有音效，没有摇摆晃动。恐怖感必须来自**结构本身**（读者自己看清了全部要素的荒谬共处）。
- **文字锚点**：《忏悔录》第四章寓言原文。
- **技术**：SVG 分层 + 滚动驱动的透明度与光照。**难度：中高**

### I-23 深渊呼吸时刻：生命的意义
- **机制**：极暗底，一句引文。光是全站唯一一次**从上往下照**（其他场景都是侧光或逆光）。引文可以被拖动——拖动时它会绕自己的轴心缓慢旋转，露出背面写着同一句话的俄文原文。
- **诠释目的**：他最终在**人民**（那些不追问意义、只是活着并劳作的农民）身上找到了继续活下去的理由，而不是在哲学里。这个"翻面看到俄文原文"的动作对应着**从思辨回到具体的语言**。

## 第七部分 · 第四乐章 深潜③《伊凡·伊里奇之死》

### I-24 三段论倒计时（签名互动 ⑪）
- **机制**：屏幕左上角是一个极小的等宽字体公式，逐行出现：
  ```
  КАЙ ЕСТЬ ЧЕЛОВЕК
  ЛЮДИ СМЕРТНЫ
  ∴ КАЙ СМЕРТЕН
  ```
  每出现一行，画面就下压 12% 的亮度。公式完成后，屏幕中央浮出伊凡的原话——那句"我学过逻辑，知道这个三段论是对的，但那是凯，不是我"。然后**整屏内容被一条横向划掉的墨线切断**（划掉"不是我"）。
- **诠释目的**：这是全书的逻辑内核：死亡的普遍性无法被任何人真正接受为"属于我的"。用倒计时 + 划线的动作把"逻辑上成立、存在上不成立"这个悖论做成一次可感知的事件。

### I-25 黑袋穿越（签名互动 ⑫）
- **机制**：一段约 400vh 的长滚动区，背景从四周向中央**收缩**：视口的可用"视野"逐渐被黑色从边缘侵蚀（用四边 mask 推进），文字被挤进一个越来越窄的竖条，行宽每滚动 100px 减少 8px，字距被挤紧，段落被迫断行成畸形。到 92% 时，可用视野只剩 26px 宽、字已经几乎不可读（但仍在，必须仍在）。到 100% 的瞬间：**黑袋从内侧被撕开**——裂纹形状（不是圆形渐变）向外扩散，光从裂缝里涌出，字重新舒展回正常行宽，"死结束了……有的是光"在完整的光里浮现。
- **诠释目的**：伊凡的原文是"他被推进一个黑袋里"、"有一股力量把他往那个黑洞里塞"，以及最后"他往袋子里看了一眼，看到了光"。**这个交互的物理性必须真的压迫读者**（行宽变窄会实际降低阅读速度），这样破裂才有意义。这是全站签名互动中最重的一个。
- **文字锚点**：《伊凡·伊里奇之死》第九章黑袋段落 + 结尾"Кончено! ... Смерти нет, есть свет."
- **技术**：CSS mask + `--p` 插值 + Canvas 撕裂路径。**难度：高**

### I-26 伊凡的同事：葬礼上的想法
- **机制**：一段原文（同事们在葬礼上想着"还好死的是他"）被拆成若干短句，随机散布在一个极淡的葬礼平面图上。读者点击任意一句，它会"归位"到原文顺序的位置；全部归位后，整段以完整段落浮现（这是全站唯一允许出现的连续段落，因为它本身就是原文的讽刺结构）。
- **诠释目的**：托尔斯泰最冷酷的一笔是：**没有人真正在乎**。让读者把散落的句子归位，恰恰是在演示"每个人都只顾自己的秩序"。

## 第八部分 · 第五乐章 深潜④《复活》

### I-27 石缝春草（签名互动 ⑬）
- **机制**：开篇的"尽管人们……把石板铺好……但春天还是春天"段落。画面是一块铺着石板的广场（俯视，浅灰石板，接缝清晰）。滚动时，从石板裂缝里极缓慢地长出小草（绿色分形曲线逐段生长，不是缩放出现）。草越长越多，石板被逐渐抬起、倾斜、露出下方的泥土。最后整个"广场"的透视被破坏。
- **诠释目的**：这就是《复活》开篇的原句意象，也是托尔斯泰晚年全部信念的图形化：**生命的力不可阻挡，人造的秩序终将被顶开**。
- **文字锚点**：《复活》第一部第一章开篇原文。
- **技术**：SVG 生长路径（`stroke-dasharray` 逐段生长）+ 滚动插值。**难度：中**

### I-28 法庭机器（签名互动 ⑭）
- **机制**：一个由齿轮、印章、滑轨组成的极简机械装置（线稿风，全部用等宽线条与 `--ash` 色）。滚动驱动它运转：传送带把一个个名字送进去，印章"咔"地盖下（每次盖章触发一次极短的 80ms 亮度脉冲），出来的是一个编号。传送带上可以看到法官、检察官这些角色**各自在旁边想自己的心事**（用极小的旁注气泡显示原文里他们的私心）。
- **诠释目的**：托尔斯泰写审判时用了一整章来写"所有人都在走程序，没有人在审判"。机器的**荒诞性来自它的高效**——所以装置必须运转得很顺滑，不能卡顿。
- **技术**：SVG + 滚动驱动的旋转角。**难度：中**

### I-29 人性摆荡条（签名互动 ⑮）
- **机制**：屏幕底部一个横向的"光谱条"：左端标"兽性的人"（`--sepia-deep`），右端标"精神的人"（`--paper-0` / 暖白）。一个游标随滚动位置与当前所读段落的内容实时摆动。当某段原文描写聂赫留朵夫被欲望支配时，游标猛地滑向左；当他决定赎罪、在他心里"那个精神的人醒过来"时，游标缓慢地滑向右。读者也可以**直接抓住游标**，把它拖到任意位置——但松手后它会根据当前位置的原文重新定位。
- **诠释目的**：这是《复活》原文里最明确的一句话结构："在他身上，就像在所有人身上一样，有两个人在斗争：一个是只为自己打算的兽性的人，一个是精神的人。"这个交互把它做成**可读的仪表**而非比喻。
- **文字锚点**：《复活》第一部关于两个"人"的原文段。
- **技术**：DOM 滑条 + 滚动插值 + 段落事件映射。**难度：中**

### I-30 复活节之吻：一吻之后
- **机制**：极暗的教堂内景（几支蜡烛的光斑）。一个"吻"的交互：屏幕中央有两点微光，鼠标从一点划向另一点时，两点之间拖出一条暖色轨迹，轨迹经过的路径上生出一行字（原文里那个吻的描写）。然后轨迹**不会消失**，而是缓慢变冷——变成冷蓝灰（`--blue`），并在旁边浮出"过了几小时，他给了她一百卢布"的一句话。
- **诠释目的**：这是全书最残酷的转折：那个复活节的吻是真的，而后的坠落也是真的。**让读者亲手画出那条轨迹、然后眼看着它变冷**，比任何解释都接近原文的运作方式。

## 第九部分 · 第六乐章「出走」

### I-31 出走地图：光线自绘（签名互动 ⑯）
- **机制**：一张极简的俄罗斯地图（只有极少的省界与地名，无任何装饰）。一条光路**自己画出来**——从亚斯纳亚波利亚纳出发，到沙莫尔金诺，到科泽尔斯克，向南，到阿斯塔波沃。光路是逐段绘制的（`stroke-dashoffset` 动画），每到一站，地图边缘的等宽小字打印一条当天的记录（气温、随行者、他说的话）。最后光路在阿斯塔波沃**停住，不闭合**。
- **诠释目的**：他一生想离开，走了 5 天，倒在了一个小车站。**地图上不画终点标记**——只有一条突然中断的线。
- **技术**：SVG path + `stroke-dashoffset` + 滚动插值。**难度：中**

### I-32 阿斯塔波沃：全球媒体事件（签名互动 ⑰）
- **机制**：以车站的极简立面（一层楼、一个站牌、几根电报杆）为中心。随着滚动，电报线从画面各处汇聚到那根电杆上（每条线携一个世界主要城市的名字与报纸名），电报杆开始"过载"（线条变得极密，出现细微抖动）。侧边栏以档案体滚动打印：记者人数、电报数量、政府封锁令。同时托尔斯泰本人的话以极小字号出现在站房窗户里，几乎被所有电报纸压住。
- **诠释目的**：**对比**：全世界在报道他的死，而他在屋里说的是"世上还有千万人在受苦，你们为什么只照顾一个列夫·尼古拉耶维奇"。这个交互的高密度是为了让读者感到压迫：世界的噪音压住了他最后的话。
- **技术**：SVG 线条动画 + 滚动插值。**难度：中**

### I-33 全世界的报纸：头条墙
- **机制**：一个斜向排布的报纸头条墙（用不同语言的等宽字体模拟，全部为 1910 年的真实报纸名与标题风格）。鼠标悬停时，该头条从灰墨变成 `--ink-0` 并轻微抬起。点击其中一两条可展开一句简短注释（说明该报的立场与报道）。
- **诠释目的**：让"最早的全球媒体事件之一"这个判断变成一次直观的密度体验。

### I-34 出走呼吸时刻：离开
- **机制**：极暗，一句引文，光从画面边缘向内收（与 I-23 相反的方向）。
- **诠释目的**：全站唯一一次"光向内收"的引文场景——离开的视觉语法。

## 第十部分 · 终章「最美的坟墓」

### I-35 茨威格：世间最美的坟墓
- **机制**：整屏极净的 `--paper-0`（全站唯一一处纹理降为 0 的场景）。中央是一段茨威格的文字，逐句浮现，极慢（每句之间 2.4s）。文字背后浮出一个极简的墓地：不是图像，而是**一道土丘的等高线**（三条极淡的曲线）。文字读完后，三条曲线缓缓闭合成一个完整的土丘轮廓。
- **诠释目的**：茨威格的核心论断是"这个世界上再也没有比这更美的坟墓了"——因为没有墓碑、没有十字架、没有名字，只有一道矩形土丘和几株树。**"什么都没有"必须真的画成"什么都没有"**：任何多余的装饰都会破坏这一章的论证。
- **文字锚点**：茨威格原文（德文关键段落 + 中译）。

### I-36 绿杖闭环（签名互动 ⑱，全站终局）
- **机制**：复用 I-03 的土层，但视角反转（向上看）。绿杖横在画面正中，发着极淡的橄榄色光。上面那行字**仍然不可读**——但这一次，读者可以把鼠标移到上面，光标变成"书写"形态，**读者可以在土层的某处写下一行自己的字**（一个 `contenteditable` 的极简输入，写在土层上，用墨色）。写完后，这行字会缓慢沉入土层（下沉并淡出），最后消失在绿色横线之下。
- **诠释目的**：**这就是"把寻找交还给读者"**。他没有找到那根绿杖上写的是什么；他把它埋回去了，并把自己葬在了上面。读者写下的那行字沉下去，全站闭环。
- **技术**：Canvas + `contenteditable` / `input` + CSS 动画。**难度：中**

### I-37 最后一屏：一句话
- **机制**：只剩一句话和一条向下的墨线（呼应首屏）。无按钮、无署名区、无页脚菜单。滚到底时，双线系统在此处**第一次完全消失**（不画了）。
- **诠释目的**：全站的双线最终不必合一，只需退场。

## 第十一部分 · 回廊（非线性自由探索区）

### I-38 牛蒡花（签名互动 ⑲）
- **机制**：一株牛蒡（репей）的 SVG 线稿，茎与叶用弹性物理建模。鼠标经过时被压弯，移开后**带阻尼地弹回**，略微过冲。反复碾压后，它会变得更"硬"，但依然弹回。旁边有一行极小的字："它还是活着。"
- **诠释目的**：《哈吉·穆拉特》开篇的牛蒡花——"多么顽强啊……它还是活着"。这个交互的核心机制（**压不垮**）就是那个意象本身。
- **技术**：SVG + 简易弹簧物理（逐节点）。**难度：中**

### I-39 与太阳赛跑（签名互动 ⑳）
- **机制**：一个横向卷动的赛跑场景（极简：一个横向的草原带 + 一个小人影 + 天上一道太阳的弧）。读者向右滚动或拖动，人影开始跑；**太阳的弧同时在推进**。进度条不是"跑了多远"，而是"太阳还有多久落山"。跑到尽头时，人影在一小块土地上停下——画面猛地变成俯视：一个 6 英尺长、2 英尺宽的土坑。**戛然而止**（滚动在这之后被"锁"住 0.6 秒的静止，然后才允许继续）。
- **诠释目的**：《一个人需要多少土地》的结尾：帕霍姆跑到了，得到了土地，然后死了，埋在那六英尺里。**这个交互必须让读者自己也"多跑一点"**——横向卷动的物理摩擦与惯性就是贪欲的手感。
- **技术**：横向滚动容器 + 滚动/拖动插值。**难度：中**

### I-40 一夜两面（签名互动 ㉑）
- **机制**：一个纵向滑杆，控制"夜的两个半场"的叠化。上：舞会（暖光、白裙、圆舞曲的弧线、上校慈爱地牵着女儿）。下：鞭刑（灰蓝天光、一列士兵、一条横向的鞭痕、同一个上校冷硬的下颌线）。滑杆停在任意位置时，**同一个人的同一处细节**（那只手/那条下颌线/那个靴跟踏地的动作）会保持在高亮状态——因为它是同一个人。
- **诠释目的**：《舞会以后》的整个结构就是这一个发现：改变伊凡的"不是他知道了什么坏事，而是他看见了**同一个人**做两件事"。因此这个交互的**唯一重点**是"同一个细节在两边的连续性"。
- **技术**：SVG + 滑杆叠化。**难度：中**

### I-41 回声墙
- **机制**：一面极淡的纸面，上面错落贴着若干"手迹卡片"（不同倾斜、不同字号、不同纸张色）。每张卡片正面只有一句话 + 一个签名缩写。点击展开：露出完整引文、原文语言、出处（书/年份/页码或章节）、以及一句 20 字以内的"这句话在反驳什么"。
- **诠释目的**：让屠格涅夫、契诃夫、福楼拜、纳博科夫、伯林、梅列日科夫斯基、高尔基、罗曼·罗兰、茨威格、列宁在同一面墙上**互相矛盾地**说话——尤其要保留列宁"天才的艺术家 vs 说教者"的两面评价，因为它正是全站要呈现的核心张力。
- **技术**：CSS grid + JS 展开。**难度：低**

### I-42 遗产光线地图
- **机制**：一张极简的世界地图（只有海岸线轮廓，`--ink-4` 色）。四条路径依次自绘：亚斯纳亚波利亚纳 → 南非约翰内斯堡（托尔斯泰农场）→ 印度（甘地）→ 美国蒙哥马利（马丁·路德·金）。每条路径以 `--line-faith` 的暖色绘制，但**线条形态沿程变化**（从手绘实线逐渐变为几何虚线再变为点线——象征思想在传递中被抽象化）。点击任意节点展开一小段原文与年份。
- **诠释目的**：这是"不抗恶"思想的世界传播路径。线条**形态的漂移**是诠释：每一次转手，思想都会变形，而它仍在传递。

### I-43 课本彩蛋：你早就认识他
- **机制**：三张卡片，正面是中文课文标题（《跳水》《穷人》《七颗钻石》），背面是对应的俄文原作名、出处文集、写作年份、以及一小段原文。翻牌动作是 3D 翻转（0.6s）。
- **诠释目的**：这是"必做彩蛋"——中国读者的共同记忆。**必须注明可信度**：如果某篇归属存疑（如《七颗钻石》），卡片背面直接标出"归属存疑"并说明。诚实比惊喜更重要。
- **技术**：CSS 3D flip。**难度：低**

### I-44 数字托尔斯泰（手稿质感计数）
- **机制**：**不是霓虹计数器**。每个数字写在一张手稿质感的小纸片上（有墨水编号与手写笔迹），数字在滚动时以"墨水逐渐渗入纸张"的方式显现（`mask` 从左上向右下推进），而不是数字跳变。数字旁以等宽小字给出该数字的出处与可信度。
- **诠释目的**：数量本身就是论证：82 年、63 年日记、13 个子女、7 遍抄写、数百个人物……**每一个数字都必须有出处**（中文网络流传的数字大量有误）。

### I-45 年表墨线
- **机制**：一条纵向的墨线（手绘质感，粗细不均），1828 到 1910。滚动时墨线**先于内容**被"画出来"（`stroke-dashoffset`），事件以极简档案体标注在线的左右两侧交替出现（年份 mono + 一句话）。点击任意事件展开一张小档案卡。墨线在 1910 年之后**继续向下画一小段空白**，然后停住。
- **诠释目的**：档案感。以及最后那段"多余的空白"——他的时间结束了，线还是画了一点。
